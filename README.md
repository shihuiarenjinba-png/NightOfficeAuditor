# NightOfficeAuditor — 深夜監査室

**開発版 v0.1 / Microsoft Store販売HOLD。** mainは履歴なしリポジトリの初期化用READMEのみです。このfeatureブランチが開発ソースの正本です。

## ゲームの体験
深夜の監査室に持ち込まれた12件の書類・取引・記録の違和感を調べ、「問題なし」「追加確認」「重大な不一致」のいずれかを報告する、オフラインの短編推理ゲームです。

限られた調査時間の中では最大2種類の証拠しか確かめられません。誤報告も見逃しも信用を損ない、慎重な「追加確認」にも機会費用があります。

### 初回の3ステップ
1. **案件を読む** — なぜおかしいかを理解する
2. **何を調べるか選ぶ** — 台帳3分・操作履歴4分・承認連絡5分から最大2つ選択
3. **自分の判断を報告する** — 検証結果・評価点・信用度を確認

専門用語やゲームの複雑な説明は増やさず、詳細な過去記録とセーブ管理は折りたたみ表示。各回の隠れた真相はシードで変化し、12件には3種類の結果を4件ずつ含む。6種類のテーマは各2回登場し、2回目は違う文脈として説明する。根拠となる主要な証拠があり、通常の情報には不確実さが残ります。

**注意：現実の監査・会計・法務の判断には使用できない、架空のゲームです。** 個人の実データや外部ネットワークは一切要求しません。

## 起動・検証
- Node.js 20以上：`npm test`。依存パッケージのインストールなし。
- ブラウザ試作：対応ブラウザで `index.html` を開く（外部API/ライブラリなし）。
- セーブはブラウザのローカルストレージに保持。JSONで書き出し・読み込み可能。読み込みできない元データは自動上書きしません。
